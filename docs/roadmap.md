# Roadmap

## Обязательное до запуска

- Проверить актуальность всех мест, ссылок и изображений.
- Настроить реальные события аналитики с согласием на обработку данных при необходимости.
- Добавить серверные CSP, Permissions-Policy и Referrer-Policy после ухода с GitHub Pages.
- Провести Lighthouse и ручную проверку на телефонах.
- Проверить лимиты и пользовательский агент выбранного провайдера маршрутизации.

## После запуска

- Вынести каталог мест и описания в структурированные данные.
- Добавить наблюдение за сбоями OSRM/Nominatim.
- Улучшить страницы маршрутов и мест для поиска, когда появится проверенный контент.

## В перспективе

- Перейти на собственный либо коммерческий API маршрутизации.
- Подготовить управляемое хранение карточек мест и редакционный процесс.
- Добавить понятную обратную связь о качестве прогулки.

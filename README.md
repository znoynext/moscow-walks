# Moscow Walks

MVP веб-приложения для умных пеших маршрутов по Москве.

## Запуск

```powershell
cd "C:\Users\user\Desktop\Вайбкодинг прогулка"
python -m http.server 8013 --bind localhost
```

Открыть:

```text
http://localhost:8013
```

Приложение работает без сборки, npm и API-ключей.

## Бесплатный стек

- Карта: OpenStreetMap через Leaflet.
- Пеший роутинг: публичные OSRM-серверы с профилем `foot`.
- Поиск адресов: OpenStreetMap Nominatim.
- Резервный режим: локальная схема, если внешний сервис временно недоступен.
- Офлайн-режим: service worker кэширует приложение, Leaflet и уже просмотренные тайлы OpenStreetMap.

Для MVP это полностью бесплатный вариант. Для большого production-проекта лучше поднять собственный OSRM/GraphHopper-сервер на данных OpenStreetMap Москвы или подключить стабильный роутинг-провайдер.

## Что делает алгоритм

- выбирает прогулочную зону Москвы;
- учитывает примерную длину, тему, ритм и обязательное место;
- учитывает примерную длину, тему и обязательное место;
- предпочитает близкие и прогулочно ценные точки;
- строит линию маршрута по пешеходной сети OpenStreetMap через OSRM;
- показывает реальную длину и время, когда OSRM доступен;
- считает примерные калории по длине маршрута;
- старается завершить маршрут рядом с метро;
- генерирует альтернативные качественные варианты.

## Подготовка к iOS

Логика уже разделена на два слоя:

- выбор точек маршрута;
- построение пешей линии между выбранными точками.

При переносе в iOS можно оставить алгоритм выбора точек, а слой карты заменить на MapLibre/MapKit/Google Maps, слой роутинга - на собственный OSRM или другой routing API.

## Офлайн-карты

Веб-версия кэширует только те тайлы карты, которые уже были открыты в браузере. Чтобы район был доступен без интернета, заранее откройте нужный маршрут и немного подвигайте карту вокруг него.

Для полноценного офлайн-доступа в iOS лучше использовать заранее подготовленные MBTiles/PMTiles или MapLibre с офлайн-пакетами.

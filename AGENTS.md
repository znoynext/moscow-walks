# Контекст проекта «Пешком.Москва»

Прочитайте этот файл перед любой работой с проектом. Он дополняет `README.md` и содержит краткий актуальный контекст для быстрого старта.

## Проект

- Статический сайт на HTML, CSS и JavaScript; сборщика и зависимостей нет.
- Сервис составляет пешеходные маршруты по Москве по старту, длине, настроению и необязательным точкам. Не меняйте алгоритм маршрутизации без отдельной задачи.
- Главная страница: `index.html`; интерфейс и логика: `styles.css`, `app.js`.
- Каталог мест: `articles.html`, `articles.js`; готовые маршруты: `routes.html`, `route.html`, `routes.js`.
- Публикация идёт через GitHub Pages по базовому пути `/moscow-walks/`; сохраняйте относительные пути.

## Актуальное SEO и бренд

- Публичное название: «Пешком.Москва». Старое название не возвращать в видимые тексты, метаданные или manifest.
- Главный поисковый фокус: «где погулять в Москве»; основной `h1` на главной — «Пешеходные маршруты по Москве».
- В `index.html` уже настроены title, description, canonical, Open Graph, Twitter metadata и JSON-LD `WebApplication`.
- `robots.txt` и `sitemap.xml` лежат в корне и доступны после публикации. При добавлении индексируемой страницы обновляйте sitemap и внутренние ссылки.
- SEO-рефакторинг от 2026-07-11 обновил бренд, главные метаданные, информационный блок на главной и публичные страницы без изменения логики построения маршрутов.
- В карточках направлений и готовых прогулок используются тематические фотографии из Wikimedia Commons через `routeImages` в `routes.js`; при недоступности изображения показывается нейтральная заглушка.
- Страница отдельной прогулки `route.html` получает маршрут по `slug`, выводит его карточку и создаёт JSON-LD через DOM API. Не вставляйте закрывающий тег `</script>` внутрь inline-скрипта: он прервёт выполнение страницы.
- Начальный масштаб Leaflet-карты задаётся константой `MAP_INITIAL_ZOOM` в `app.js` и сейчас равен `10`, чтобы показывать Москву с ближайшими районами.
